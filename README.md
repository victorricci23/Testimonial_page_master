## Overview

![screenshot](https://media.discordapp.net/attachments/1464634656463786118/1564654088300527616/solution.png?ex=6ae20d2c&is=6ae0bbac&hm=58058415c752b3323c9e62b3cd1d8d22f48427c321f2bd2875f7bb403093e715&=&format=webp&quality=lossless) <!-- Add a screenshot or GIF of your solution here -->

This project is a responsive **Testimonial Page** created as part of the [devChallenges.io](https://devchallenges.io/) challenges. It displays reviewer guidelines alongside user feedback/testimonials with star ratings, seamlessly adapting to various screen sizes ranging from desktop to mobile devices.

### What I learned

- Structuring web pages using semantic HTML elements.
- Building flexible layouts using CSS **Flexbox** properties (`flex-direction`, `align-self`, `justify-content`).
- Writing responsive media queries (`@media`) to handle custom breakpoints (e.g., `< 857px` and `857px - 1024px`).
- Importing and using Google Web Fonts (`Sora`).

### Built with

- Semantic HTML5 markup
- CSS custom properties & Flexbox
- Media Queries for responsive design
- [Google Fonts (Sora)](https://fonts.google.com/specimen/Sora)

## Features

- **Responsive Layout:** Automatically stacks components vertically on tablets and mobile screens while displaying side-by-side on desktop displays.
- **Card Styling:** Clean visual design using soft drop shadows (`box-shadow`), rounded corners, and star icon ratings.
- **Cross-device Support:** Custom media queries tailored to provide optimal viewing across different screen thresholds.
